# Server rules

> **Sample page:** change the rules to your own, delete this note, and set `"enabled": true` for this page in `config/stats_webui_plus.json`.

1. **Be kind.** No insults, harassment or discrimination, in chat or anywhere else.
2. **No griefing or stealing.** Don't destroy or take what others have built or collected.
3. **No cheating.** No hacked clients, X-ray or exploits. Allowed: [mods such as minimaps].
4. **Farms are welcome**, as long as they don't make the server lag.
5. **Ask before building close to someone else.**
6. **Have fun!**

Questions? Ask [an admin / on our Discord].
