# Screenshots

Sample players on a Fabric dev server, taken with the scripts in [`scripts/`](../scripts/README.md). The default banner, two extra menu buttons from the config (`links`) and a custom page (Rules) in the menu. Pages other than the start page open at their content, with the banner scrolled away and the slim menu bar on top, as they do in the browser. Every icon is drawn by the mod from the game's textures, which it downloads from Mojang at the server's first start.
